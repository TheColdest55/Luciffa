酒桌快玩

2 人无需道具约 3 分钟

十五二十

双方同时出手并猜两个人手指数量的总和，是最经典的数字拳之一。

玩法一：轮流喊数

  1. 每个人同时使用两只手：双手握拳代表 0，伸开一只手代表 5，双手伸开代表 10。
  2. 进攻方出手的同时喊出 0、5、10、15、20 中的一个数字。
  3. 如果喊出的数字等于双方手势总和，进攻方猜中；否则换对方喊。
  4. 常见规则是连续猜中两次才赢一局，也可以约定猜中一次即胜。

玩法二：双方同时喊数

  1. 两个人同时出手，并同时喊出 0、5、10、15、20 中的一个数字。
  2. 只有一方喊中双方手势总和时，喊中的一方直接获胜。
  3. 双方同时喊中时，本轮不分胜负，继续下一轮。
  4. 双方都没喊中时，同样继续下一轮，直到有且只有一方喊中。
开局前先约定采用哪种玩法；轮流喊数时，还要约定猜中一次还是连续两次获胜。
参考：数字拳规则
3 人以上无需道具反应类

逢七过

按顺序报数，碰到和 7 有关的数字时不能直接说出来。

玩法

  1. 从 1 开始，所有人按座位顺序依次报数。
  2. 遇到 7 的倍数，或数字中含有 7，例如 7、14、17、21、27，要拍手或说“过”。
  3. 说错数字、该拍手时报数、重复或停顿太久，都算本轮失误。
  4. 失误后可以从 1 重新开始，也可以从任意数字继续。
熟练后可以加入“拍手后反转方向”，难度会明显提高。
参考：逢七过玩法示例
2 人以上手机或纸笔猜数字

数字炸弹

在不断缩小的范围内猜数字，猜中隐藏数字的人“踩中炸弹”。

玩法

  1. 主持人在 1～100 中确定一个秘密数字，不能让其他人看到。
  2. 玩家轮流在当前范围内猜一个数字。
  3. 主持人回答秘密数字更大或更小，并立即缩小有效范围。
  4. 例如秘密数字为 63，有人猜 40 后，范围变成 41～100；再猜 80，范围变成 41～79。
  5. 最终猜中秘密数字的人本轮失败，然后更换主持人开始下一局。
人数多时可把范围扩大到 1～500；想更快结束则使用 1～50。
参考：数字炸弹规则介绍
2 人以上每人 5 颗骰子和骰盅心理博弈

大话骰

玩家只能看到自己的骰子，通过叫数、加码和质疑判断全场骰子数量。

玩法

  1. 所有人同时摇骰，只查看自己骰盅里的结果，并对其他人保密。
  2. 第一位玩家叫“X 个 Y”，例如“三个 4”，表示他认为全场至少有三个 4。
  3. 下一位必须提高叫法，例如增加数量，或在相同数量下提高点数；也可以直接喊“开”。
  4. 有人喊开后，全体亮骰。如果实际数量达到叫数，质疑者输；没有达到，则上一位叫数者输。
  5. 可采用输一轮减少一颗骰子的计分法，最后仍有骰子的玩家获胜。
常见玩法把 1 当作万能点数，但叫过 1 后是否继续万能，各地规则不同，开局必须先说清楚。
参考：大话骰规则
3 人以上无需道具接龙类

逛三园

围绕一个类别快速接龙，考验知识量和临场反应。

玩法

  1. 发起人说：“星期天，逛三园，什么园？”
  2. 下一位选择一个类别，例如水果园、动物园、汽车园或电影园。
  3. 随后每个人依次说出一个属于该类别的项目。
  4. 内容重复、不属于类别、超过约定时间没有回答，都算失误。
  5. 失误者接受一次挑战，并负责选择下一轮的类别。
类别最好至少能说出十个答案，太窄的类别容易让游戏立刻结束。
参考：逛三园玩法说明
2 人无需道具节奏猜拳

舞拳

把节拍动作、石头剪刀布和方向判断连在一起的双人反应游戏。

采用常见的“猜拳＋上下左右指向”版本。

玩法

  1. 两人面对面，先按统一节拍完成四拍甩手或拍手动作。
  2. 节拍结束后，同时出石头、剪刀或布。
  3. 猜拳平局时，直接重新按节拍猜拳。
  4. 猜拳分出胜负后，胜利者和落败者都同时用手指向上、下、左、右中的一个方向。
  5. 两人所指方向相同，猜拳落败者输掉本轮；方向不同则重新开始。
方向环节双方都用手指出方向，不需要转头。不同地区的前奏拍数可以自行约定。
参考：舞拳动作教学示例
4 人以上无需道具破冰聊天

我有你没有

轮流说一件自己做过、认为别人没做过的事情，用手指记录剩余机会。

玩法

  1. 每个人伸出五根或十根手指，代表自己的生命值。
  2. 玩家轮流说：“我有……的经历，你们没有。”内容必须真实。
  3. 其他没有做过这件事的人放下一根手指；做过的人保持不动。
  4. 手指最先全部放下的人出局，最后仍有手指的人获胜。
不讨论隐私、违法经历或可能让别人不舒服的话题；任何人都可以跳过问题。
参考：我有你没有活动规则
4 人以上一副扑克牌指令牌

小姐牌

去掉大小王后轮流抽牌，每个点数对应一个即时任务或可保留的能力。

牌义没有全国统一标准，下表采用常见网络版本。
A代罚牌：需要接受挑战时，可指定另一人代替一次。
2小姐牌：抽到者获得“陪伴角色”，直到下一张 2 出现。
3逛三园：指定类别后依次接龙，重复或答不出者失败。
4照相机：持牌者可突然喊“照相机”，所有人定格，先动者失败。
5免罚牌：可以抵消一次挑战。
6摸鼻子：持牌者随时摸鼻子，最后跟着摸的人失败。
7逢七过：开始一轮含 7 或 7 的倍数拍手的数字接龙。
8离席牌：可获得一次暂停或离席权。
9抽到者自己接受一次挑战。
10神经病：别人不能回答持牌者的问题，回应者失败。
J抽牌者左边的人接受一次挑战。
Q抽牌者右边的人接受一次挑战。
K累计牌：第一张 K 设定数量，后续抽到 K 的人按约定执行。
涉及陪伴、离席或代罚的指令必须尊重本人意愿，可以统一改成扣分。
参考：小姐牌常见牌义
4 人以上一副扑克牌独立变体

大姐牌

大姐牌与小姐牌不是同一套规则，核心是“大姐裁定”、组合任务和持续绑定。

采用目前较常见的网络流传版；开局前应逐张确认牌义。
A盲选牌：随机选中一名玩家，由牌桌给出一个友好小挑战。
2红色 2 为小姐；黑色 2 为大姐。大姐可裁定请求、解除绑定或修改一次任务。
3N＋1 园：回答时先重复上一人的答案，再增加一个新项目。
4对战牌：抽牌者选择一人与自己玩任意一轮小游戏，失败者受罚。
5抱团牌：持牌者突然喊人数，大家按该人数抱团，落单者失败。
6扭一扭：从“一棵柳树扭一扭”开始逐人增加数量，卡顿或说错者失败。
7五七反应：遇到 5 的相关数字摇头，遇到 7 的相关数字拍手。
8铁锁连环：选择另一人绑定；一人接受挑战时另一人也记一次，需由大姐解除。
9抽牌者自己接受一次挑战。
10美杜莎：所有人先低头，再同时抬头看一人；互相对视者失败。
J右边的人接受挑战。
Q左边的人接受挑战。
K规则牌：抽牌者制定一条持续规则，下一张 K 出现时替换。
大姐牌流传时间较短、版本差异尤其大。这一页记录的是可直接开局的整理版，不宣称是唯一规则。
参考：大姐牌变体资料
3 人以上一副扑克牌记忆与 bluff

金字塔

把牌摆成金字塔逐层翻开，玩家利用手牌匹配牌点并分配挑战，也可以尝试虚张声势。

采用四层、共十张金字塔的常见版本。

准备

  1. 去掉大小王，把十张牌面朝下摆成 4、3、2、1 的四层金字塔。
  2. 每位玩家发四张手牌，查看并记住后面朝下放在自己面前。

玩法

  1. 从最底层开始，每次翻开一张金字塔牌。
  2. 如果玩家声称自己的手牌中有相同点数，就能把本层对应数量的挑战分配给别人：底层 1 次，向上依次 2、3、4 次。
  3. 被指定者可以接受，也可以质疑。被质疑者翻开手牌验证。
  4. 声明属实，质疑者承担；声明不实，虚张声势者承担。
  5. 所有金字塔牌翻完后结束。
参考：金字塔喝酒游戏
2 人以上一副扑克牌连续猜牌

过三关

连续完成猜颜色、猜大小和猜区间三项判断，三关全部正确才算过关。

“过三关”名称有多种含义，本页采用扑克牌猜牌版。

玩法

  1. 第一关：发牌前猜下一张是红色还是黑色，猜完后翻开第一张。
  2. 第二关：猜第二张比第一张大还是小，然后翻牌；相同点数可约定重抽。
  3. 第三关：猜第三张的点数位于前两张之间还是区间之外，然后翻牌。
  4. 三关全部正确即成功；任意一关失败，本轮结束并轮到下一位。
A 算最大还是最小、点数相同时怎么处理，都应在开局前统一。
参考：猜红黑／大小／区间玩法
3 人以上一副扑克牌五张牌比牌

抓老二

所有人使用五张牌比大小，第一名获胜，而排名第二的人是本轮主要目标。

采用目前网络“抓二游”的简化线下版，不等同于大老二。

玩法

  1. 去掉大小王，给每位玩家发五张牌。
  2. 玩家整理自己的五张牌型，然后同时亮牌。
  3. 牌型从大到小采用：同花顺、四条、葫芦、同花、顺子、三条、两对、对子、散牌。
  4. 牌型相同时，依次比较组成牌型的主要点数，再比较剩余大牌。
  5. 最高者为头游；第二高者为“老二”，承担本轮约定的挑战。
网上“抓二游”计分随平台变化。这一版只保留“第二名被抓”的核心，不涉及下注或倍数。
参考：抓二游玩法介绍

经典棋牌

3 人54 张牌阵营对抗

斗地主

一名地主对阵两名农民，任意一方率先出完手牌即获胜。

准备与阵营

  1. 使用一副含大小王的 54 张牌，每位玩家先获得 17 张，剩余 3 张作为底牌。
  2. 通过叫分或叫地主确定地主；地主获得三张底牌，另外两人组成农民阵营。
  3. 地主先出牌，之后按顺序轮流出牌。

基本牌型

  • 单张、对子、三张、三带一、三带二。
  • 顺子至少五张，连对至少三对；2 和王不能进入顺子。
  • 飞机由连续三张组成，可按规则带相同数量的单牌或对子。
  • 四张相同点数是炸弹；大小王组成火箭，为最大牌型。

压牌与胜负

  1. 通常只能用张数相同、类型相同且更大的牌压过上一手。
  2. 炸弹可以压普通牌型，更大的炸弹可继续压；火箭最大。
  3. 不想出或无法压牌可以选择不要。其余两家都不要时，最后出牌者开启新一轮。
  4. 地主先出完则地主胜；任意农民先出完则农民阵营共同获胜。
参考：三人斗地主规则概览
4 人两副牌两人组队

掼蛋

四人分成两队，对家为队友；在跑牌基础上加入级牌、配牌、升级和进贡。

以下是帮助新手开局的简化说明，正式比赛还包含更细的判罚规则。

准备

  1. 使用两副完整扑克牌，共 108 张，每人 27 张。
  2. 相对而坐的两人是一队。
  3. 首局通常从打 2 开始，当前所打点数称为“级牌”。

牌的大小与牌型

  • 大王、小王和级牌属于较大的特殊牌；红桃级牌通常可作为“逢人配”代替其他普通牌。
  • 常见牌型有单张、对子、三张、三带二、顺子、连对、钢板、炸弹和同花顺。
  • 一般牌型需用相同类型的更大牌压；炸弹和同花顺拥有更高压制能力。

出牌、排名和升级

  1. 玩家依次出牌，可以压过上一手或选择不要。
  2. 其余玩家都不要后，最后出牌者获得下一轮首出权。
  3. 按出完手牌顺序分为头游、二游、三游和末游。
  4. 头游与二游若为同队，通常升三级；头游与三游同队通常升两级；头游与末游同队通常升一级。
  5. 下一副可能进行进贡、还贡或抗贡，然后继续升级，先打过 A 的队获胜。
掼蛋地方规则较多，尤其是顺子范围、同花顺与炸弹大小、报牌和进贡细节；正式对局建议采用同一份竞赛规则。
参考：国家体育总局棋牌中心掼蛋赛事资料
